# Layout

- [Header](header.md): the global application bar with logo, main navigation, shortcuts and account.
- [Side Navigation](side-navigation.md): collapsible left rail to move between the sections of a dossier or area.
- [Page Header](page-header.md): topbox, breadcrumbs, page title with actions, and tabs at the top of a page.
- [Drawer](drawer.md): right-hand panel for a secondary task (filters, details) that keeps the page in view.
- [Modal](modal.md): blocking dialog for a focused task, in four sizes.
