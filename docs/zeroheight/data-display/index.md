# Data Display
Components of the [Components] Data Display library (Figma file `VpConH5AUGyCqtp8PMqj1i`).

- [Card](card.md): white container with title, actions and label and value columns, in six types (Default, Key Info, Company Profile, Redirect, Slot, Empty State).
- [Card with Slot (Widget Card)](widget-card.md): board widget card with an optional header and a free content slot (chart, list, figures).
- [Table](table.md): data grid built from header rows, rows, cells, selection and flyout cells.
- [Collapsible Table](collapsible-table.md): a table section with a category header that expands and collapses its rows.
- [Topbox](topbox.md): summary strip of the current object (buyer or policy) at the top of the Page Header.
- [Horizontal Card](horizontal-card.md): generic full-width result row with slots, favorite and expandable details.
- [Grade](grade.md): credit grade pill (manual, automatic, not computed, not applicable) with an optional score.
- [Policy color](policy-color.md): policy color pill (Green, Yellow, Orange, Red, U, N) with an optional label.
- [Accordion](accordion.md): a titled section that expands and collapses its content.
- [Timeline](timeline.md): chronological list of events with status, grouped in collapsible categories.
- [Identifier](identifier.md): read-only ID chip with optional icon, copyable on demand.
- [Icon Tile](icon-tile.md): square tile holding one icon that says what kind of object a row is.
- [Progress Bar](progress-bar.md): thin bar for a value out of 100 (score, completion).
- [List Item](list-item.md): one entry of a board widget list (task, note, news).
- [Chart](chart.md): line chart frame for board widgets (grid, axes, series slot).
