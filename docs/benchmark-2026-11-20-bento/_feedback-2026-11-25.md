# Retours utilisateur du 2026-11-25 (Buyer Summary V2)

Spec commune au code (src/app/pages/buyer-summary-v2/) et à Figma (fichier Bento XW7jVtIa6UWRTqKMDqOF5D, page Mockups
118:3983 ; librairie Data Display VpConH5AUGyCqtp8PMqj1i). « Commence par ces modifs et on affinera après. »

1. **Plus de détail de card en drawer.** Supprimer le drawer « card details » qui s'ouvre sur le côté, et tous ses
   points d'entrée (clic sur le titre, « See figures », « View data », items de menu). Les liens de pied de card qui
   menaient au détail disparaissent (ou pointent vers la vraie page métier si elle existe déjà dans le proto : sinon,
   rien). Figma : supprimer l'écran 9 « Card detail » des Mockups et resserrer la grille d'écrans.

2. **« Add a card » beaucoup plus visuel, beaucoup moins de lecture.** Aujourd'hui : titre, description, valeurs,
   aperçu carrousel, choix de format, choix d'emphase : trop d'informations pour faire un choix. À la place :
   - le drawer garde un champ de recherche en haut, puis des groupes courts (par sujet métier) de **vignettes
     visuelles** ;
   - chaque vignette = une miniature schématique de la card (le **type** de contenu se reconnaît d'un coup d'oeil :
     gros chiffre, courbe, barres, liste, tableau, jauge), SANS valeurs réelles, SANS description ; dessous, un nom
     court (1 à 3 mots : « Exposure », « Payments », « Jobs to do ») ;
   - un clic (ou Entrée) pose la card au premier emplacement libre dans son format par défaut ; le glisser reste
     possible ; le format et l'emphase se changent ensuite avec la barre d'outils de la card (plus dans la galerie) ;
   - une card déjà sur le board est marquée discrètement (coche ou « On board »), pas cachée ;
   - accessible : chaque vignette est un bouton avec un nom accessible complet (nom + ce qu'elle montre), focus
     visible, navigation clavier dans la grille.

3. **Supprimer « Highlighted » et l'étoile.** Le fond Subtle ou Strong suffit à dire l'emphase. Aucune étiquette ni
   icône d'emphase manuelle dans l'en-tête des cards (les statuts calculés Warning / Problem / On track restent,
   avec leur icône et leur raison). Code : garder seulement un texte pour lecteur d'écran si utile. Librairie :
   retirer la valeur Highlighted de `.Status` dans les variantes Subtle et Strong de Widget Card (sans casser les
   propriétés) puis republier ; Bento suit après mise à jour.

4. **Manage boards simplifié.**
   - En haut, la liste des **boards modèles** (templates) : sélectionnables pour les appliquer / ouvrir, NI
     renommables, NI supprimables, NI réordonnables, pas de « Reset to template ».
   - En dessous, la liste des **boards personnels** : renommer, supprimer (« on supprime et basta », avec le filet
     Undo déjà en place si simple), pas de flèches de réordonnancement, pas de « Duplicate » dans ce drawer.
   - Supprimer les flèches et la fonction « Reset to template ». La copie ne se fait pas ici.
   - La création d'un board perso reste possible ailleurs (sélecteur de board : « New board », vide ou à partir d'un
     modèle) si elle existe déjà ; sinon ne pas l'inventer ici, le signaler.

5. **Plus de point médian « · » comme séparateur.** Il fait « IA ». Utiliser le trait d'union classique « - », ou
   réorganiser (deux lignes, libellé + valeur). Dans toute l'interface de la V2 et dans les maquettes Figma (textes,
   pas besoin de renommer les calques). Le « - » est un trait d'union simple, jamais un tiret cadratin.

Règles inchangées : tokens Semantic seulement, composition stricte des atomes DS, pas de tiret cadratin, densité et
bord bas propre, textes d'interface en anglais.
