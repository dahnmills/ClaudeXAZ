Orphans — replacement candidates

For each component that's built but never adopted, is there a native pattern in the pages that could adopt it? Checked CSS by CSS, not just by shape — a surface resemblance isn't enough (see Select Button / Tile).

  • Flyout (base panel)

    → replace with this one
    What we have
    buyer-summary.component.html:96-126 — .bs-toolbar (native div)
    Replace with
    ds-flyout — Design System/Layout/Flyout

    ⚠ ds-flyout is a role="dialog" with a 290px min-width (visible above, wider than the compact toolbar) — built for a dropdown menu, not a hover toolbar. Needs adapting before a real swap.
